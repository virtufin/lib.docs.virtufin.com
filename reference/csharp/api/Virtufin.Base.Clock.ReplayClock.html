Class ReplayClock

Namespace
Virtufin.Base.Clock

Synthetic replay clock for hyp scenarios. Starts at a configurable offset and can be advanced deterministically by a step. The clock name encodes the selector (e.g. synthetic:BTC_202101_202206).
