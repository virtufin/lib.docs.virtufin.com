Live executor base for routing actions to a real exchange. Subclasses define the exchange-routing strategy in Process(TState, TAction). No assumptions about routing, fallback, or state evolution — all in the subclass.

Remarks

Template method pattern. Execute(TState, TAction) delegates directly to Process(TState, TAction); subclasses own the full routing flow. The base previously held a deterministic fallback for development; that has been removed to keep the base free of routing-strategy assumptions. Subclasses may compose a fallback of their own if they want one.

Remarks

Production subclasses will marshal the action to a wire protocol (REST, FIX, gRPC, native API), await the exchange's response, and translate it to a TEvent. In development subclasses may choose to no-op, log, or delegate to a local simulation — the base does not constrain this.
