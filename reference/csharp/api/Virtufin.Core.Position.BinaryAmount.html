Fixed-point amount with base 2 (binary scaling), stored as a whole part, a fractional part, and a precision (number of binary fraction digits). The represented value is Whole + Fraction / 2^N.

Remarks

Exists alongside DecimalAmount to exercise and prove the base-agnosticism of IFixedPointAmount and FixedPointArithmetic. Arithmetic follows the same rules: addition/subtraction require a common base and precision; equality/ordering reject mismatched precision with PrecisionMismatchException.
